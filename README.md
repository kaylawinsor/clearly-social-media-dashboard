# Clearly Social Media Dashboard — Live Demo

This is the **live demo** of the [Clearly Social Media Dashboard](https://clearly-social-media-dashboard.vercel.app) — a single-file, offline social media analytics dashboard for creators and small-business owners, sold on Etsy.

- Pre-filled with sample data, fully clickable — every number is editable and every rate recalculates as you type.
- **Demo edits reset on refresh.** The full version autosaves to your device and adds Backup & Restore.
- No accounts, no uploads: everything runs in your browser from one file.

This repository contains only the locked demo build.
